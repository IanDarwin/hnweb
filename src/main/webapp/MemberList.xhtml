CSV format dumps for short-term use: Current (Paid-up) List - Complete (including some historical) List - Save, or do View Source and copy, to make them look right! Notes on Member Data

There is a Member Type field, with values FM, FS and IND. Individual is obvious. FM is Family - master member. FS is Family- secondary.

I've not been totally consistent in filing familes (this database was originally from a spreadsheet that had a few more irregularities). Sometimes if all the secondary's info is the same they're listed in a single FM entry (e.g., John & Jenny Jones), sometimes they're both listed even though all info is the same. However the main reason for listing them separately is when they have the different emails, or different last names, or when one or both has an executive position.

The "includes many historical" includes non-renewed as well as all members I've ever had in the database. Except for the small number that I deleted before member archiving was completed. Most deleted ones can be un-deleted if they rejoin later.

Pages that need to run something when they open (e.g. load a member from the memberId request parameter) put an f:metadata element inside a ui:define named "metadata". It MUST be defined there: f:metadata placed anywhere else in a template client is ignored. <ui:insert name="pageTitle">Members</ui:insert> - #{config.orgName}
